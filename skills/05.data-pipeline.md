## 2. Text Sanitization & OCR Normalization

PDF text extraction frequently introduces artifacts that degrade test quality:
1. **Broken Words Across Line Wraps**: Words split with trailing hyphens (e.g. `imple- \n mentation` $\to$ `implementation`).
2. **Quotation & Typographical Standardization**:
   - Curly quotes `“`, `”`, `‘`, `’` normalized to clean single/double quotes.
   - Dashes `--`, `—`, `–` standardized to regular em-dashes.
3. **Artifact Removal**: Page numbers, header banners, watermarks (e.g. `Question X of 194`, `Page 12 of 85`) stripped out using regular expressions.
4. **Encoding Safety**: Strict UTF-8 enforcement to preserve Vietnamese diacritical marks (`à, á, ả, ã, ạ, ê, ơ, ư, đ`).

## 3. Data Mirroring Architecture

To support both browser execution without build tools and command-line data maintenance, data files are maintained in tandem:

| Asset | Format | Purpose |
|---|---|---|
| `data/cards.js` | `const ALL_CARDS = [...];` | Executable script loaded by `index.html` via `<script>` tag |
| `data/cards.json` | `[...]` | Raw JSON mirror for Python/Node.js tooling, test scripts, and external tools |
| `data/quiz.js` | `const QUIZ_DATA = [...];` | Executable script loaded by `index.html` |
| `data/quiz.json` | `[...]` | Raw JSON mirror for verification scripts |

### Automated Sync in `fix_quiz.js`
When updates are applied to the quiz bank:

## 4. Automated Quality Assurance & Verification Scripts

Every release and update must pass automated verification checks before being committed:

### Check 1: Option Length Parity
Ensures no single option acts as an obvious tell due to extreme brevity or excessive length:
```python
def check_length_parity(questions):
    flagged = []
    for q in questions:
        lengths = [len(o) for o in q['options']]
        if min(lengths) / max(lengths) < 0.4:
            flagged.append(q['id'])
    return flagged
```

### Check 2: Duplicate Option Detection
Guarantees that all 4 choices in every question are mutually distinct:
```python
def check_duplicate_options(questions):
    for q in questions:
        if len(set(q['options'])) < 4:
            raise ValueError(f"Duplicate option in {q['id']}")
```

### Check 3: Translation Completeness
Verifies that no bilingual fields are left blank:
```python
def check_translation_coverage(questions):
    for q in questions:
        assert q.get('questionVi'), f"Missing questionVi in {q['id']}"
        assert len(q.get('optionsVi', [])) == 4, f"Missing optionsVi in {q['id']}"
        assert q.get('explanationVi'), f"Missing explanationVi in {q['id']}"
        if q['type'] == 'sjt':
            assert q.get('scenarioVi'), f"Missing scenarioVi in {q['id']}"
```
