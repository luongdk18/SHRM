# Skill 04: Active Recall & Flashcard Pedagogy

## 1. Pedagogical Foundation
The flashcard engine is grounded in cognitive science principles:
- **The Testing Effect**: Actively retrieving knowledge from memory produces significantly stronger neural encoding than passive re-reading.
- **Desirable Difficulty**: Forcing learners to recall the term from a definition and real-world scenario before revealing the answer accelerates conceptual mastery.
- **Dual-Coding Theory**: Presenting definitions alongside practical workplace scenarios (*Tình huống*) and exam trigger keywords (*Mẹo thi*) creates multiple cognitive retrieval pathways.

## 2. The 4-Step Card Study Loop

```
┌────────────────────────────────────────────────────────┐
│                   THE FLASHCARD LOOP                   │
│                                                        │
│   Step 1: Read Stimulus                                │
│   [ Definition (EN + VI) + Workplace Scenario ]        │
│                         │                              │
│                         ▼                              │
│   Step 2: Mental Retrieval                             │
│   [ Formulate the Term in Memory ]                     │
│                         │                              │
│                         ▼                              │
│   Step 3: Reveal & Validate                            │
│   [ Tap "Reveal Term" -> Inspect Term & Exam Tips ]    │
│                         │                              │
│                         ▼                              │
│   Step 4: Self-Rate & Progress                         │
│   ┌─────────────────────┴─────────────────────┐        │
│   ▼                                           ▼        │
│ [ Still Learning ]                        [ Got It ]   │
│ (Retain in Deck;                         (Mark Done;   │
│  Scroll to top)                          Advance next) │
└────────────────────────────────────────────────────────┘
```

### Step 1: Stimulus Presentation (Front of Card)
The card displays:
1. `card-prompt`: `"What is this term?"`
2. `card-def`: English formal definition.
3. `card-def-vi`: Vietnamese accurate translation.
4. `card-scenario`: A concrete workplace situation illustrating the term in action.

### Step 2: Mental Retrieval
Learners pause to retrieve the term from memory prior to interacting with the UI.

### Step 3: Reveal & Validation (Back of Card)
Clicking `Reveal term` executes an in-place reveal (unfolding without page reload):
1. `card-term`: The target technical SHRM term.
2. `card-tag`: The cluster and functional domain badge.
3. `card-tip`: High-yield exam recognition tips (*Mẹo thi*), warning of common confusions (e.g. *Point-Factor vs Ranking*, *Title VII vs ADA*).

### Step 4: Self-Evaluation Semantics
- **"Still Learning"**:
  - Hides the answer and exam tips.
  - Smoothly scrolls card back to the top (`scrollCardToTop()`).
  - Keeps the card active in the current session queue for immediate re-attempt.
- **"Got It"**:
  - Moves the card ID from `deck` to `done`.
  - Persists completed status in `localStorage`.
  - Advances immediately to the next remaining card.

## 3. Segmented Domain & Cluster Filtering

The application allows learners to target specific weakness areas or master clusters systematically:

```
All Domains (392 Cards)
 ├── Competencies Cluster (103 Cards)
 │    ├── Leadership & Navigation
 │    ├── Ethical Practice
 │    └── ...
 ├── People Cluster (113 Cards)
 │    ├── HR Strategy
 │    ├── Talent Acquisition
 │    └── ...
 ├── Organization Cluster (66 Cards)
 └── Workplace Cluster (110 Cards)
```

### Isolated Session Progress
Each filter key maintains independent progress tracking:
```javascript
// Session key format:
// 'all' | 'cluster:People' | 'domain:Total Rewards'
sessions[sessionKey] = {
  deck: ["0", "5", "12", ...],  // Remaining card indices
  done: ["1", "2", "3", ...]    // Completed card indices
};
```
Switching from "All Domains" to "Total Rewards" and back preserves exact progress in both study sessions.

## 4. International Learner Adaptation (US Law Toggle)

Many global candidates take the SHRM exam outside the United States and may not be tested heavily on domestic U.S. statutory compliance.

### The `US` Button Toggle
- **Default State**: `US off` (Hidden).
- **Mechanism**: Filters out all 35+ cards in the `U.S. Employment Law & Regulations` domain.
- **Persistence**: Persisted across sessions in `shrm-flashcards-hide-us-law`.
- **Learner Autonomy**: One-tap toggle at the top right allows U.S.-based practitioners to re-enable domestic compliance instantly.

## 5. Reshuffle & Reset Protocols

- **Reshuffle Remaining (`reshuffle()`)**:
  Re-randomizes only the uncompleted cards in the active deck. Completed cards remain marked as done.
- **Reset Progress (`resetProgress()`)**:
  Prompts for confirmation, then resets `done` array to empty and restores all cards back into `deck` for the active filter only.
